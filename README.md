# Practice_SQL
Practicing SQL from basics
1	SQL Basics (SELECT, WHERE, GROUP BY, HAVING)	Solve 10 filtering/aggregation problems
2	Joins (INNER, LEFT, RIGHT, FULL, CROSS)	Write 5 complex join queries
3	Subqueries (Correlated, Nested)	Solve 5 problems using subqueries
4	Set Operations (UNION, INTERSECT, MINUS)	Practice 3 real-world scenarios
5	Indexes & Optimization	Optimize 3 slow-running queries
6	Window Functions (RANK, DENSE_RANK, LEAD/LAG)	Solve 5 analytical problems
7	Recursive Queries (Hierarchical Data)	Write 2 recursive CTEs
8	Pivoting & Dynamic SQL	Convert 3 row-based datasets to columns
9	Transactions & Isolation Levels	Simulate deadlocks/concurrency issues
10	Performance Tuning (EXPLAIN PLAN, Hints)	Analyze 2 query execution plans
